## Intent

这是一支 MoeReview 的产品介绍视频。它把项目定位从“学习工作区”讲清楚为“以发现和阅读论文为主、深入学习为辅”的本地论文平台。叙事从用户打开论文时的门槛开始，展示发现流、中文大白话摘要、中文/原文/双语阅读、图表与 PDF 核对、收藏和继续阅读，最后进入解析、问答、术语和做题。

## Assets

无外部素材。视频中的界面是依据当前 MoeReview Web UI 和项目契约重构的可渲染产品界面，用于说明真实功能路径。

## Customizations

- 中文字幕式叙事，所有主要功能同时以大字号界面文字呈现。
- 视觉方向：深色、低眩光、编辑部阅读工作台；薄网格、局部光晕和结构化面板作为背景层。
- 重点展示本地优先、统一 API 配置、翻译档位和“中文术语（English keyword）”规则。
- 结尾保留产品边界：原版 PDF 仍是图表、表格、公式和版式的视觉事实来源。

## Notes

- 视频不声称联网自动扫描全网；最高翻译档展示为“自动处理本机已发现论文”。
- 不展示真实 API Key、真实用户数据或运行缓存。
